# Space RAG

## Agentic Multimodal Retrieval-Augmented Generation

Space RAG is an AI system designed to answer questions about
satellite and remote-sensing documents.

## Main Features

- PDF document understanding
- Text retrieval
- Dense semantic retrieval
- Visual document retrieval using ColPali
- Hybrid retrieval
- Agentic query decomposition
- Iterative retrieval
- Cross-modal consistency verification
- Grounded answer generation
- Fine-grained citations
- Automatic evaluation

## Architecture

PDF
→ Document Processing
→ Multimodal Indexing
→ Hybrid Retrieval
→ Agentic Reasoning
→ Cross-Modal Verification
→ Answer Generation

## Technology Stack

- Python
- LangGraph
- LlamaIndex
- ChromaDB
- BM25
- BGE
- ColPali
- Qwen
- Streamlit
